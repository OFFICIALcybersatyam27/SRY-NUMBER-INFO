📌 About

SRY NUMBER INFO is a colorful terminal-based phone number metadata viewer designed for educational and informational purposes.

This tool can display public phone metadata such as:

- Validation Status
- Carrier Information
- Country & Region
- Timezone
- Number Type
- Number Formatting
- History System
- TXT Export

⚙️ Installation

Step 1 — Update Packages

pkg update && pkg upgrade

Step 2 — Install Python

pkg install python

Step 3 — Install Git

pkg install git

Step 4 — Clone Repository

git clone https://github.com/OFFICIALcybersatyam27/SRY-NUMBER-INFO.git

Step 5 — Open Folder

cd SRY-NUMBER-INFO

Step 6 — Install Requirements

pip install phonenumbers
pip install colorama
pip install pyfiglet
pip install tabulate

OR

pip install -r requirements.txt

---

▶️ Run Tool

python Sry.py
